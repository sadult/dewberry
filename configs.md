# Dewberry configurations

Place one share-link per line. Lines that are not valid links are ignored,
so you can freely mix in Markdown headings, notes and code fences.

```
# Example (replace with your own):
# vless://uuid@example.com:443?type=ws&security=tls&sni=example.com#My-Server
# vmess://base64payload==
# trojan://password@example.com:443#Trojan-Server
```

Use **Manual Import** on the Configurations page to load this file, or point
the **Fetch** button at the raw URL of a file like this hosted on GitHub.
